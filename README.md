A FreeCAD workbench for building parametric 3D routes (pipes, cables, ducts) with automatic generation of solid bodies.

## Features
- Parametric polyline from spreadsheet coordinates
- Builder panel for adding segments (axis + length)
- Cross-linked coordinates and vectors tables
- Automatic pipe, box, and rectangle generation
- Attachment to existing geometry (vertices)
- STEP export
- Hotkeys, color-coded phantom, dynamic markers
